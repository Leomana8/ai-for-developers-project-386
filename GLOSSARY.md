# Календарь звонков

Упрощённый сервис бронирования времени по мотивам Cal.com: Владелец календаря публикует
доступное время, Пользователь выбирает свободный Слот и записывается на звонок. В проекте нет
авторизации, личных кабинетов и интеграций с внешними календарями.

## Language

**Пользователь**:
Тот, кто записывается на звонок: видит свободные Слоты и выбирает один из них.
_Avoid_: Гость, клиент, посетитель, бронирующий

**Владелец календаря**:
Тот, кто публикует доступное для звонков время и просматривает предстоящие Встречи.
_Avoid_: Хост, организатор, владелец

**Слот**:
Конкретный промежуток времени, доступный для записи.
_Avoid_: Таймслот, окно, интервал, слот времени

**Встреча**:
Назначенный звонок — то, что Пользователь получает в результате Записи, а Владелец календаря
видит в списке предстоящих.
_Avoid_: Запись, бронь, бронирование, событие, мероприятие

**Запись**:
Действие Пользователя по выбору Слота, в результате которого создаётся Встреча.
_Avoid_: Бронирование, резервирование
